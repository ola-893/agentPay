AgentPay · Design research · 27 October 2026

Clear money. Explainable decisions.
Visible guardrails.

Eight public Mobbin screens across five products, selected for AgentPay’s financial overview, workflow evidence and service-failure journeys.

Recommended combination: Midday’s financial hierarchy + Databricks’ run history + Front’s detail drawer + Better Stack’s operational states.
Public screen references only. Authenticated flow playback was not tested. No product implementation changed.
MiddayCurrent UI

Dashboard Overview

Understand the money

Observed
A leading monetary total and chart sit above secondary spending and invoice summaries.
Adapt for AgentPay
Give funded, earned and refunded USDC clear visual priority beside the workflow. Display observed amounts with their source run.
Keep honest
A revenue chart is a layout reference; it does not establish AgentPay savings or a live vault balance.

DatabricksCurrent UI

Query History

Inspect a workflow run

Observed
A dense execution table pairs status icons with start time, duration, source and filters.
Adapt for AgentPay
Use compact decision rows for action, reason, time, run and execution status. Keep BLOCK and ERROR outcomes discoverable.
Keep honest
These are query-history screenshots, not observed CRE step playback. A proposed AgentPay row-to-evidence interaction is our adaptation.

FrontCurrent UI

Contact Details Panel

Understand a decision

Observed
A selected list row stays visible beside a right-side details drawer.
Adapt for AgentPay
Keep the diagram or decision list in context while showing the selected rule, observed input, bound, decision, permit and receipt evidence.
Keep honest
The reference contains contact data. Financial fields and decision explanations would come from AgentPay evidence, not from the reference product.

Better StackCurrent UI

Incident Dashboard

Respond to service failure

Observed
An incident list exposes service, start time and assignment, with explicit status and setup progress.
Adapt for AgentPay
Distinguish service unavailable, CRE unavailable, closure requested, transaction pending and stream closed. Show the last observation time.
Keep honest
An unavailable provider does not mean accrual already stopped. Continuous monitoring and automatic recovery are not implemented.

MiddayCurrent UI

Transaction Table

Trace payment and audit activity

Observed
A searchable transaction table separates date, description, amount, category, account and status.
Adapt for AgentPay
Separate stream funding, recipient earnings, refunds and receipt gas. Link transaction hashes to their actual operations. Keep blocked decisions visible without inventing payment transactions.
Keep honest
A confirmed audit receipt anchors a record; it is not a completed payment. This is not a request to add an accounting product.

v0Current UI

Billing and Usage Settings

Read limits without ambiguity

Observed
Plan, credit balance, recharge setting, payment method and invoices are grouped into separate cards.
Adapt for AgentPay
Separate available funds, workflow limits and contract limits, with asset units and reset scope. In the current deployment, the contract deposit cap is 0.01 USDC while the registered workflow cap is 0.1 USDC.
Keep honest
The source is billing presentation, not a verified spending-policy editor. AgentPay has no rolling daily onchain budget yet.

FrontFuture architecture

Setup Guide Modal

Prepare a live agent integration

Observed
A setup guide groups tasks into a checklist with a progress indicator and a completed item.
Adapt for AgentPay
Use explicit prerequisites for registered agent, matching policy authority, USDC, gas, CRE authentication and recovery readiness. Keep credential-free replay available separately.
Keep honest
A new operator cannot currently provision a fresh deployment through a complete supported onboarding flow. No setup UI was implemented in this research pass.

MiddayFuture architecture

Accounts List

Manage per-agent vaults

Observed
Connected bank accounts are grouped by institution, with individual account rows, balances and an add-account action.
Adapt for AgentPay
After guarded vaults exist, group an agent identity with its vault address, USDC balance, committed funds, allowed services and authority status.
Keep honest
AgentPay currently has one agent-bound stream escrow, not automatically provisioned per-agent vaults. The source does not demonstrate crypto funding or vault custody.
